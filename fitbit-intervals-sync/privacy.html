Privacy policy

Last updated: 17 October 2026

fitbit-intervals-sync is a personal tool run by Alex Gaignard, used only with the author's own account.

Data accessed

With the account holder's consent, the tool reads these read-only Google Health API data types: sleep, daily heart rate variability, daily resting heart rate, daily oxygen saturation, daily respiratory rate, daily VO2 max, steps, weight and body fat.

How it is used

Once a day, the tool copies these values for the previous and current day into the account holder's own intervals.icu account. It does nothing else with them.

Storage and sharing

The tool has no database and keeps no copy of health data. Values pass through a GitHub Actions run and are sent only to intervals.icu. The OAuth credentials are stored as encrypted GitHub Actions secrets. No data is sold, shared with third parties, used for advertising, or used to train AI models.

Google API Services User Data Policy

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
